# Blinkit Sales Dashboard 📊

## 📌 Project Overview
This dashboard analyzes Blinkit sales performance, outlet trends, and customer ratings using Power BI.

## 🔍 Key Insights
- Tier 3 outlets generated the highest sales
- Fruits & Snacks are top-performing categories
- Average customer ratings are consistent (~4.0)
- Item distribution varies across outlet types

## 🛠 Tools Used
- Power BI
- Excel
